# Findings & Recommendations

## Findings

Findings are evidence-backed issues or observations from Engineering Intelligence.
Each finding typically includes severity, domain, rule identity, and evidence
pointers into the repository.

## Recommendations

Recommendations suggest modernization or remediation actions derived from findings.
They are not automatic code changes.

## In the IDE

The CodeStrata VS Code Extension loads findings and recommendations from
**public** assessment artifacts produced by the Engine — it does not
re-implement analysis.
