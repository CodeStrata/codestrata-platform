# Deterministic vs AI

| Mode | Flag | Requires | Role |
| ---- | ---- | -------- | ---- |
| Deterministic (default) | `--no-ai` | Engine only | Rules + evidence → findings |
| Optional AI | `--with-ai` | Your provider credentials | Enrichment / advisor layers |

**Deterministic assessment remains the default.** AI is a capability of CodeStrata
Engine, not a separate product name.

Do not confuse Engine AI credentials with CodeStrata Platform API keys.
