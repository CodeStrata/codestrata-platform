# Security

## Documentation portal

This site:

- Requires no authentication
- Collects no credentials
- Ships no secrets
- Avoids analytics by default
- Avoids unnecessary cookies and third-party embeds

## Community Engine

- Assessments run locally under your control
- Optional AI uses **your** provider credentials
- Do not commit secrets or private repository paths into docs PRs
