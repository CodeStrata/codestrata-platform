# Privacy

## Documentation site

- No account required
- No analytics by default
- Future analytics require an explicit privacy review

## Local assessment

CodeStrata Engine processes repositories on your machine (or CI you control).
CodeStrata does not retain your source code through this documentation portal.

IDE extensions invoke the Engine locally and do not store provider credentials in
the extension for Community assessment flows.

See the repository `PRIVACY.md` policy file.
