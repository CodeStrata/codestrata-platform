# FAQ

## Is CodeStrata Community Edition free to use locally?

Community Engine and the VS Code extension are intended for local Community use under
their published licenses (see GitHub). Platform and commercial products are separate.

## Do I need the cloud to run an assessment?

No. Deterministic assessments run locally with CodeStrata Engine.

## Does the VS Code extension upload my source?

The extension does not upload repository source. Optional AI enrichment is Engine-owned
and uses your configured provider — see [AI Providers](/ai-providers/) and
[Privacy](/security/privacy).

## Why is progress indeterminate?

Assessments do not expose trustworthy percentage completion to the extension. Progress
is shown as an indeterminate lifecycle until the Engine result is known.

## Which CLI versions work with the VS Code extension?

Marketplace listing **0.2.1** (and the 0.2.x extension line) supports Engine CLI
`0.2.x` release builds (no prerelease). See [Compatibility](/reference/compatibility).

## Where is Platform documentation?

Commercial Platform documentation is outside this Community documentation site.
