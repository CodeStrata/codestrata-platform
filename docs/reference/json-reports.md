# JSON Reports

CodeStrata Engine emits machine-readable artifacts alongside `assessment.html`,
typically at:

```text
.codestrata-artifacts/assessments/<repository-id>/current/assessment.json
```

IDE extensions and automation consume these **public** contracts.

Exact schemas and versioning live with Engine public contracts. See
[Public Contracts](./public-contracts) and [Findings](./findings).
