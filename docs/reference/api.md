# Community API

Community developers primarily use the **CLI**. Engine may expose additional
programmatic surfaces documented with Engine public contracts.

## Community Cloud HTTP API

Observable Community Cloud ingestion contracts are documented at:

- [Community Cloud API](/reference/community-api/) — `https://api.codestrata.ai`

Developers can inspect network requests and compare them with those contracts.

## Primary interface

- [CLI reference](/reference/cli) — assess, init, doctor, version
- [Public contracts](/reference/public-contracts) — schemas and compatibility notes
- Optional [MCP](/reference/mcp) for agent tooling

## Boundaries

Organizational REST surfaces and commercial Platform APIs are **not** part of
Community Edition documentation. Local Engine installs do not require Community
Cloud services. Insights administrative APIs are private and not documented as
Community APIs.
