# MCP

CodeStrata Engine can expose MCP tools when installed with the `mcp` extra and
enabled in configuration.

```bash
python -m pip install 'codestrata[mcp]'
```

MCP is optional Community surface for agent tooling against Engine capabilities.
It is not CodeStrata Platform Retrieval/Answering.

Technical tool catalogs remain in Engine documentation; this portal covers the
public positioning and install boundary.
