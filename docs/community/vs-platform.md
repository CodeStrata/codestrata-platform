# Community vs Platform

**CodeStrata Engine** helps a team understand and improve a repository.  
**CodeStrata Platform** helps an organization persist, connect, retrieve, and
reason across repositories.

## Community includes

- Local repository assessment
- Deterministic Engineering Intelligence
- Local reports (HTML + JSON)
- CLI
- API and MCP where publicly supported by Engine
- Examples
- VS Code Extension
- Cursor Extension
- Developer-configured AI providers

Community assets:

- CodeStrata Engine
- CodeStrata Examples
- CodeStrata VS Code Extension
- CodeStrata Cursor Extension
- CodeStrata Documentation

## Platform includes

Commercial capabilities such as:

- Centralized organizational operation
- Engineering Knowledge Graph
- Repository Retrieval and Answering
- Portfolio Intelligence
- Portfolio Retrieval and Answering
- Executive Intelligence
- Strategic roadmap experiences
- Organizational governance
- Commercial deployment and support

Learn more: [https://codestrata.ai/platform](https://codestrata.ai/platform)

## Rules of thumb

| Rule | Meaning |
| ---- | ------- |
| Engine alone is useful | Platform is not required to assess or report |
| Platform may depend on Engine | Engine must not require Platform for Community assess |
| Credentials differ | Engine AI keys ≠ Platform API keys |
| No false Community claims | Platform features are not available inside Community by default |

More: [Platform overview](/platform/).
