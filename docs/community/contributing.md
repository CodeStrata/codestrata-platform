# Contributing

Thank you for improving CodeStrata documentation.

1. Follow contribution guidance in this page and the repository `CONTRIBUTING.md`.
2. Follow terminology: CodeStrata, CodeStrata Engine, CodeStrata Platform.
3. Prefer working Community commands only.
4. Do not document private Platform implementation details.
5. Run `npm test` before opening a pull request.

Engine-specific contributor guides remain in the Engine repository.
