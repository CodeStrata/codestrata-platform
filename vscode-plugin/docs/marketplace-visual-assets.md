# Marketplace visual assets (Slice 14.6)

Policy: `codestrata-marketplace-visual-assets-policy:1.0`  
Mapping: `policies/design_system_marketplace_mapping.json`  
Manifest: `policies/marketplace_visual_manifest.json`

## Purpose

Align VS Code Marketplace packaging visuals with Design System 1.0 so the listing
matches the Community experience on codestrata.ai, Community docs, Assessment HTML,
and the VS Code extension (Slice 14.5 presentation).

Marketplace listing **copy** remains Slice 13.13. This slice changes **visual assets**
(icon, gallery banner, screenshots, captions/alt text references) only.

## Marketplace icon

- Packaged: `media/codestrata-icon.png` (128×128)
- Classification: **marketplace-specific derivative** (not the universal logo)
- Distinct from the activity bar SVG (`media/codestrata-activity.svg`, `currentColor`)
- Regenerated by `scripts/generate_marketplace_visuals.py` from Design System tokens
- Universal asset authority is established in Slice **14.10**: the icon is an approved raster
  derivative whose bar geometry is projected from the master mark, recorded in
  `design-system/contracts/assets.json`

## Regeneration

```bash
.venv/bin/python vscode-plugin/scripts/generate_marketplace_visuals.py
```

Deterministic local generation: no network, no remote fonts required for verification
metadata, no timestamps in policy/manifest outputs.

When Extension Host / Playwright capture is unavailable, representative Design System
framed product surfaces are used and recorded as a verification limitation.

## Non-goals
