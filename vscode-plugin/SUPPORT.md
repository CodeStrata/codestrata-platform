# Support

**Product:** CodeStrata VS Code Extension (Community Edition)  
**Depends on:** CodeStrata Engine CLI

## How to get help

1. Command Palette → **CodeStrata: Open CodeStrata Output**
2. **CodeStrata: CodeStrata Doctor**
3. Engine Quick Start: https://github.com/CodeStrata/codestrata-engine/blob/main/docs/quick-start.md
4. Engine troubleshooting: https://github.com/CodeStrata/codestrata-engine/blob/main/docs/troubleshooting.md
5. Extension documentation / support: https://docs.codestrata.ai/extensions/vscode

## Community scope

Local repositories, local Engine, local reports, optional AI via Engine providers.  
**Not included:** CodeStrata Platform APIs, multi-tenant control planes, Enterprise Edition.
