Design System **1.0** remains the token authority. Slices 14.7–14.10 add
presentation, visualization, report information-architecture, and brand-asset
usage contracts under `design-system/contracts/` without bumping the Design
System version. Slice 14.10 additionally makes `design-system/assets/brand/` the
authoritative home for master brand assets. Slice 14.11 adds accessibility and
responsive acceptance contracts under the same Design System version. Slice 14.13
adds cross-surface visual consistency policy under Design System 1.0.
