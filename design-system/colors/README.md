# Colors

Authority: live website `:root` variables (2026-08-07).

## Primary surfaces

| Token | Hex | Role |
| ----- | --- | ---- |
| canvas | `#f4f6f3` | Page background |
| paper | `#ffffff` | Elevated paper / controls |
| paper-soft | `#f8f9f7` | Soft cards / panels |
| ink | `#111815` | Primary text |
| muted | `#5f6b65` | Secondary text |
| line | `#d6ddd8` | Borders / rules |

## Accents

| Family | Hex | Use |
| ------ | --- | --- |
| teal / teal-dark | `#16756a` / `#0f5d54` | Primary CTA, focus, success |
| rust | `#a04b17` | Warning / emphasis / risk |
| blue | `#4d6885` | Informational only (not primary brand accent) |

## Dark (night)

Use `--night*` family for dark theme: `#101a17` canvas, `#edf3f0` ink.

## Rules

1. Teal is the interactive brand accent.
2. Rust is semantic emphasis / risk — not decorative chrome.
3. Blue is informational — never the primary CTA fill.
4. Accent budget: ≤3 accented elements per viewport height.
