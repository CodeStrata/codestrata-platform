# Layouts

| Pattern | Rule |
| ------- | ---- |
| Wrap | `min(100% - 64px, 1160px)` centered |
| Marketing header | Sticky, blurred canvas, 3-column nav grid |
| Hero | Brand-first; one headline; one supporting sentence; CTA group |
| Sections | One job per section; generous vertical rhythm |
| Cards | Prefer bordered paper; avoid dashboard card walls in heroes |
| Footer | Simple link clusters; ink on canvas |

No full-bleed purple gradients. No multi-stat hero strips.
