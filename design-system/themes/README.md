# Themes

## Light (default)

`color-scheme: light` — canvas `#f4f6f3`, ink `#111815`, accent teal-dark.

## Dark (night)

Map surfaces to `--night*` family. Accent shifts to teal (brighter on dark).
Code blocks remain dark-preferring in both themes when showing terminal output.

Theme toggle is a later-slice concern; tokens must support both modes now.
