# Typography

| Role | Family | Notes |
| ---- | ------ | ----- |
| Display / headings | Space Grotesk | weight 500–600; lh ~1.12 |
| Body | Inter | 16px / 1.65 |
| Facts / code | IBM Plex Mono | paths, IDs, commands, JSON |

## Register split

- **Proportional** carries argument and persuasion.
- **Mono** carries measured facts only (≤ ~10% of visible text).

## Scale

See `tokens/catalog.json` → `typography.scale` (xs → display).

Observed hero H1 ≈ 44–48px; section H2 ≈ 36px; UI chrome ≈ 12–14px.
