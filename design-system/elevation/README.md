# Elevation

Live site is mostly **flat**.

| Level | Token | Use |
| ----- | ----- | --- |
| none | `none` | Buttons, default cards |
| soft | `0 18px 48px rgba(24, 40, 34, 0.08)` | Sparse floating emphasis only |

Do not introduce multi-layer purple glow shadows. Prefer 1px borders over heavy
elevation for structure.
