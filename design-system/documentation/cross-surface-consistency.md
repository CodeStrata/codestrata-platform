## Posture

CodeStrata surfaces share one product identity and one semantic design language.
They are not required to be pixel-identical.

Approved adaptations include native VS Code host chrome, offline report font
stacks, Marketplace raster derivatives, and Swagger framework shell bridging.

## Authority

All active surfaces resolve to Design System **1.0**. Public token mirrors under
`docs/public/design-tokens/` and Swagger `design-tokens/` must track that
authority. Amber-era primary identity is not active.
