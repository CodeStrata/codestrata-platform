# Icons

| Attribute | Rule |
| --------- | ---- |
| Style | Monoline stroke; geometric; no skeuomorphism |
| Weight | Match thin social/nav strokes on website |
| Color | Inherit ink/muted; teal only for semantic status |
| Logo | Horizontal strata bars (multi-color lockup preserved) |
| Directional | Simple arrows in buttons (`→`, `↗`) |

No emoji as product UI icons.

Slice 14.10 owns brand and icon authority: the master mark, its approved
derivatives, and the icon-language contract. See
[`../documentation/brand-assets.md`](../documentation/brand-assets.md) and
[`../contracts/icons.json`](../contracts/icons.json). The Marketplace package icon
is a raster derivative regenerated from the master mark.
