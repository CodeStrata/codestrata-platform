# Commercial Boundary Verification (Slice 6.12)

Engineering Intelligence Report capabilities are **Commercial / Platform-only**.

This document records the architectural boundary verified at the close of Epic 6.
It does not introduce product features.

## Ownership

| Capability | Owner |
| --- | --- |
| Single-repository assessment (`report.json`) | Engine / Community |
| Validation records / summaries | Engine validation harness |
| `EngineeringIntelligenceReport` | Platform `intelligence_reporting` |
| Dataset ingestion | Platform |
| Cross-repository aggregation | Platform |
| Technology distribution | Platform |
| Capability comparison | Platform |
| Recurring patterns | Platform |
| Modernization observations | Platform |
| Report confidence / dataset limitations | Platform |
| Repository drill-downs | Platform |
| Website-safe export (JSON/HTML/manifest) | Platform |
| Public OSS demonstration report | Platform (`platform/demo/`) |

## Isolation rules

1. **Engine** remains a single-repository assessment engine. It must not contain
   commercial intelligence models, builders, exporters, presentation, CLI, APIs,
   or persistence for multi-repository Engineering Intelligence.
2. **Community Edition** must not expose portfolio / multi-repository commercial
   intelligence. Public export must never include `platform/`.
3. **Platform** owns all commercial Engineering Intelligence packages under
   `platform/src/codestrata_platform/intelligence_reporting/`.
4. **Imports:** Engine and Community must not import `codestrata_platform`.
   Platform may import approved Engine reporting/traceability contracts for
   ingestion only. There is no reverse dependency.
5. **OSS demonstration** artifacts live only under `platform/demo/` and are
   generated by Platform-only code.

## Public export

[`public-export-manifest.yaml`](../../../public-export-manifest.yaml) forbids
`platform/` (and therefore all commercial Engineering Intelligence code) from
Community mirrors such as `codestrata-engine` and `codestrata-examples`.

export exclusion, schema versions, and OSS demonstration Platform ownership.
