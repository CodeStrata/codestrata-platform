# Design Partner Onboarding

**Status:** Foundation  
**Authority:** Playbook

## Objective

Onboard design partners safely with clear boundaries, environments, and success
criteria.

## Scope

Partner evaluation of CodeStrata Engine and/or CodeStrata Platform.
Not a sales playbook.

## 1. Prerequisites

- [ ] NDA / partner agreement in place (process outside repo)
- [ ] Environment chosen (local Engine vs hosted Platform)
- [ ] Sample repositories agreed (non-sensitive preferred first)
- [ ] Success criteria documented

## 2. Access

## 3. Guardrails

1. No production customer source without explicit approval.
2. API keys rotated after engagement.
3. Partners get capability boundaries (Community vs Platform) explained up front.
