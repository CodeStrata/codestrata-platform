# CLI

```text
codestrata architecture assessment inspect --artifact …/architecture-assessment.json
codestrata architecture assessment findings --artifact …
codestrata architecture assessment conclusions --artifact …
codestrata architecture assessment recommendations --artifact …
codestrata architecture assessment coverage --artifact …
codestrata architecture assessment limitations --artifact …
codestrata architecture assessment traceability --artifact …
```

`--json` is supported. The assess command remains `codestrata assess`.
