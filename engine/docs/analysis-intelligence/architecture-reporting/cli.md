# CLI

Inspect presentation content from `report.json` (no re-analysis):

```bash
codestrata architecture report inspect --report path/to/report.json
codestrata architecture report conclusions --report path/to/report.json
codestrata architecture report recommendations --report path/to/report.json
codestrata architecture report findings --report path/to/report.json
codestrata architecture report coverage --report path/to/report.json
codestrata architecture report limitations --report path/to/report.json
codestrata architecture report traceability --report path/to/report.json
```

All commands support `--json`.

Assessment-layer CLI remains under `codestrata architecture assessment …`.
