# CodeStrata Community Edition

CodeStrata **Community Edition** is the open-source, MIT-licensed product you
install from this repository. It is designed for individual engineers and teams
assessing **one repository at a time** on a local machine.

Enterprise capabilities that require portfolio governance, multi-tenancy, or
hosted platform services are **out of scope for Community Edition**. Some
Enterprise-oriented modules ship in-tree as **optional / disabled-by-default**
so contributors can develop against shared methodology without implying a
hosted Platform product.

## Principle

> Community helps teams understand and improve software.  
> Enterprise helps leaders understand, govern, and modernize an engineering organization.

See also
[assessment-framework/community-enterprise-boundary.md](assessment-framework/community-enterprise-boundary.md).

## Included in Community Edition

| Area | Status |
| ---- | ------ |
| Local / GitHub repository scan & assess | Included |
| Technology detection (Java, JS/TS, Python, PHP, C#/.NET) | Included |
| Dependency evidence (Maven, npm, Composer, NuGet) | Included |
| Deterministic rules → findings → recommendations | Included |
| HTML Report v2 + JSON artifacts | Included |
| Optional one-call Bedrock AI enrichment | Included (optional extra) |
| Local knowledge store & repository knowledge (deterministic) | Included |
| Local FastMCP server | Included (optional `mcp` extra) |
| Agent Framework (local orchestration) | Included |
| Incremental assessment (opt-in) | Included |
| Shared Rule Platform / analysis packs (feature-gated) | Included when enabled |
| Execution profiles (`community`, `local`, `bedrock`, `openai`, …) | Included |
| Sample apps + sample reports | Included |

Default execution profile: **`community`**
([configuration-profiles.md](configuration-profiles.md)).

## Optional in-repo, disabled by default

These ship for shared methodology and contributor workflows. They are **not**
Community Edition defaults and are not a hosted Platform:

| Capability | Gate | Notes |
| ---------- | ---- | ----- |
| Enterprise Knowledge Graph (YAML) | `[enterprise].enabled` / profile `enterprise` | Present in monorepo for Platform; **excluded from public Community export** |
| Many assessment/report pack sections | Feature flags in `codestrata.toml` | Off until explicitly enabled |

## Explicitly out of Community Edition (future Platform / Enterprise)

Marked as placeholders — **not implemented as hosted product services**:

* Multi-tenancy, RBAC, SSO, audit control planes
* Billing / subscriptions
* Centralized report management & org workflows
* Portfolio scoring / comparative benchmarking SaaS
* Managed cloud suppressions and proprietary rule marketplaces
* Hosted multi-repo control plane

## Enterprise KG packaging decision (Phase 5.24)

* **Monorepo:** Enterprise KG runtime may remain under `engine/src/codestrata/**/enterprise`
  for Platform development (still disabled by default).
* **Public Community export (`codestrata-engine`):** Enterprise KG runtime modules,
  CLI adapters, MCP enterprise tools, and schemas are **excluded**.
* Community builds keep an extension hook (`codestrata.extensions`) so Platform can
  supply Enterprise capabilities without Community importing `platform/`.
