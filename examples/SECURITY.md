# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| current main | Yes |

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities, and
**do not disclose publicly** before coordinated release of a fix or advisory.

Report privately via a GitHub Security Advisory on this repository (when
enabled), or via the security contact listed on the repository profile.

Include a description, reproduction steps, and affected revisions if known.

You should receive an acknowledgment within **7 days**.

## Scope

This repository contains showcase manifests and expected results only. It does
not ship the CodeStrata Engine runtime. Do not commit secrets, tokens, or
`.env` files.
