# Contributor Covenant Code of Conduct

## Our Pledge

We pledge to make participation in the CodeStrata Community a harassment-free
experience for everyone.

## Our Standards

Examples of positive behavior:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Focusing on what is best for the community

Unacceptable behavior includes harassment, trolling, or publishing others’ private information.

## Enforcement

Report issues to maintainers via GitHub on the public repository.
